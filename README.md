## 🎯 Project Overview

The **Lost & Found Portal** is a web-based platform designed for a college campus where students and staff can **report lost items, report found items, and safely return items** using a **simple approval-based system**.

The system works on **public visibility**, **real-time notifications**, and **owner approval**, ensuring that **only the real owner receives the item**.

- ❌ No private chat
- ❌ No admin dependency
- ❌ No complex verification
- ✅ Only logic, transparency, and confirmation

---

## 👤 Roles

1. **Person who LOST the item**
2. **Person who FOUND the item**

---

## 🔐 Features Highlights

### 🔔 Real-Time Notifications
- Alerts to all logged-in users when a lost or found post is created.

### 🤝 Safe Handovers
- Approval-based return system ensuring secure and error-free returns.

### 🔄 Auto-Expiry System
- Posts auto-close after a fixed duration to keep the system clean.

---

## 🛠️ Features & Flow

### 1️⃣ Lost Item Posts

When a user loses an item, they create a **Lost Item Post**. They enter:
- Item name
- Approximate location
- Time/Date
- Description
- Notifications are instantly sent to all users.

### 2️⃣ Found Item Approaches (Two Options)

✅ Respond to Lost Post:<br>
- Finder clicks "I Found This" and shares location details.<br>

✅ Independent Found Post:<br>
- Finder creates a **new post** mentioning item details & pickup location.

---

### Core Security

- Finder sends a **return request** to the original lost post owner.
- Owner approves or rejects the return request.

## 🧠 Smart Enhancements

## 🚀 Getting Started

Follow these instructions to clone, build, and run the project locally:

### Prerequisites
- Node.js (v16 or above)
- MongoDB

### Installation
```bash
# Clone this repository
git clone https://github.com/Pratyakshgupta887qwert/CampusFind-Lost-Found-Portal.git
cd CampusFind-Lost-Found-Portal

# Install dependencies
npm install

# Add environment variables in `.env`
# Run the app
npm start
```
